# Read trending tweets

Fetch global trending tweets.

## Endpoint

`GET /twitter/global-trending/tweets`

SDK: `client.trending.tweets`. CLI: `x-api-scraper trending tweets`.

Ask for country, topic, or content when the user wants a filtered slice.
